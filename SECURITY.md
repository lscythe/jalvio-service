# Security Policy

## Reporting a vulnerability

Report vulnerabilities privately through [GitHub's private vulnerability reporting](https://github.com/lscythe/jalvio-service/security/advisories/new). Do not open a public issue.

Include what is affected, how to reproduce it, and the impact you expect. You will get a reply within 7 days.

## Supported versions

Only the latest commit on `main` receives fixes.
